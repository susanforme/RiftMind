# 三期 UI 审阅

2026-10-19，Mac / Chromium，真实 Rust harness、临时 SQLite 与合成远端。

- `live-*`：公开选人、匿名、换英雄、结束状态；中英文、浅深色和 800×600。
- `champions-*`：英雄池、缓存范围、逐项样本、分组近期胜负和 ECharts。
- `compare-*`：固定两侧输入/报告、结算、缺失值及时间对齐图表；事件按需展开。
- `issues-*`：跨场分母、证据引用、目标草稿与确认启用。
- 另使用 agent-browser 实际导航、检查暗色主题，并用键盘选择队列、核对路由筛选。最终页面截图取自包含实体图片的 harness E2E。

截图中的开发场景工具栏属于 harness；生产构建隔离检查通过。
800×600 的表格可在其容器内横向滚动，文档本身没有横向溢出。数据是合成样本；不代表真实联网或 Windows 原生界面验收。
